# NAYRO — site

Site institucional da NAYRO (Next.js 16 + Prisma + Supabase), com painel em `/admin` para cadastrar projetos e serviços.

- Configuração, painel e publicação: veja [PASSO-A-PASSO.md](PASSO-A-PASSO.md).
- Variáveis de ambiente: copie `.env.example` para `.env` e preencha.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # gera o Prisma Client e o build de produção
```
